CSS livre

Mude qualquer coisa do visual. Salvou, aplicou.

Exemplos pra copiar 
/* Cantos mais arredondados nas mensagens e avatares */
[class*="avatar"] img { border-radius: 30% !important; }

/* Fonte diferente */
body { --font-primary: "Segoe UI", sans-serif; }

/* Esconder o botão de presente (Nitro) na caixa de mensagem */
button[aria-label*="presente" i], button[aria-label*="gift" i] { display: none !important; }

/* Esconder a barra de rolagem */
::-webkit-scrollbar { width: 0 !important; }
